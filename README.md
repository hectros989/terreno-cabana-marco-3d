# Terreno y cabaña — Visor 3D

Visor web interactivo del modelo arquitectónico. Abre `index.html` mediante GitHub Pages para explorar el modelo en el navegador.

## Archivo del modelo
Coloca `modelo.dae` en la raíz del repositorio, junto a `index.html`.

## Publicación
En Settings → Pages, selecciona Deploy from a branch, rama `main` y carpeta `/(root)`.

Nota: el archivo DAE original referencia texturas externas que no estaban incluidas en el paquete recibido; algunas superficies podrían no mostrar sus texturas originales.
